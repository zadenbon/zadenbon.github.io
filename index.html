10 Things i actually use

Semantic HTML

Markup that means something, so screen readers and search engines understand the page without extra work.

Flexbox and Grid

Layouts that hold together on a phone and a monitor without a pile of media query hacks.

CSS animation

Motion handled by the browser's own compositor, so it stays smooth without JavaScript doing the work.

Canvas and SVG

Drawing straight to the pixel for anything a normal element can't do.

Forms and validation

Inputs that catch a mistake before it reaches a server, and say so out loud for anyone using a screen reader.

Accessibility

Keyboard navigation, visible focus states, and labels that work for people who aren't using a mouse.

Vanilla JavaScript

No framework between me and the page. Smaller files, fewer surprises.

Responsive design

One codebase that works from a small phone up to a wide monitor.

Performance

Pages that load fast because nothing unnecessary got shipped in the first place.

Custom interactions
